## 简体中文

这是一个围绕 Herbert Amann 与 Joachim Escher 的三卷本分析学教材 *Analysis I–III* 建立的非官方学习项目，按教材章节整理独立编写的习题解答，帮助读者复习定义、梳理论证并核对解题思路。项目与作者及出版方无关联。

### 内容范围

- **Analysis I**：目前已有第 I–V 章的解答，主题包括基础逻辑与代数、数列与级数、连续函数与拓扑、一元微分，以及函数列与函数逼近。
- **Analysis II、Analysis III**：已建立卷册导航页，习题解答内容尚待整理。

习题解答正文目前主要使用英文；本 README 提供中英文介绍。

### 编写约定

- 习题编号对应教材；完整题目请查阅教材原文。
- 解答尽量写明使用的假设与关键推理步骤。
- 数学公式使用适用于 GitBook 的 LaTeX 格式。

本仓库以 Markdown 文档为主，可直接在线阅读，也可克隆后浏览 `docs/` 目录。欢迎通过 Issue 或 Pull Request 提出勘误与改进建议。

## English

This is an unofficial study project for Herbert Amann and Joachim Escher’s three-volume textbook *Analysis I–III*. It organizes independently written exercise solutions by chapter to help readers review definitions, follow proofs, and check their reasoning. This project is not affiliated with the authors or publisher.

### Scope

- **Analysis I**: Solutions are currently available across Chapters I–V, covering foundational logic and algebra, sequences and series, continuity and topology, one-variable differentiation, and sequences and approximation of functions.
- **Analysis II and Analysis III**: Volume navigation pages are in place; exercise solutions have not yet been added.

The solution notes are currently written mainly in English. This README is available in both Chinese and English.

### Conventions

- Exercise numbers follow the textbook; consult the book for the full problem statements.
- Solutions aim to state their assumptions and make the key reasoning steps explicit.
- Mathematical expressions use GitBook-compatible LaTeX notation.

The repository consists primarily of Markdown documents. Read them online or clone the repository and browse the `docs/` directory. Corrections and suggestions are welcome through Issues or Pull Requests.
